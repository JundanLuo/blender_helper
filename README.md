# BlenderHelper

Blender scene, camera, lighting and rendering utilities for [ProjectiveShading](https://github.com/JundanLuo/ProjectiveShading/).

## Setup

- Tested with Blender 3.6.14. GPU rendering uses NVIDIA OptiX.
- Place this repository at `blender_helper/` inside ProjectiveShading.
- Follow ProjectiveShading’s environment setup and usage guides. Its pipeline calls these utilities automatically.
